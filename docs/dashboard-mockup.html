Design notes. Colour marks abnormality only (ISA-101): Normal = neutral grey, amber = Siaga, red = Bahaya, cobalt = accent (nav/focus/selection). Cobalt Mono theme, base #09090b. Level 1 is map-first; the Overview widgets slide in from the Overview button. Level 2's chart is 3 stacked lanes sharing one time axis; bands live only in the Tilt lane. Status names (Normal / Siaga / Bahaya) follow the official BNPB LEWS scale. The map here is a static placeholder; the real build uses Leaflet + CARTO dark_matter. Real build type system: Fira Sans + Fira Code (this mockup uses system fonts — the artifact CSP blocks font CDNs).
